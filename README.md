# AI Student Support Assistant

A simple beginner-friendly web application that helps students get answers to common college-related questions.

## Features
- College FAQ knowledge base
- Simple RAG / retrieval
- Office timing tool
- Student name memory
- Simple web chat interface

## Technologies
- Python
- Flask
- HTML
- CSS
- JavaScript
- JSON
